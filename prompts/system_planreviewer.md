# Задача
1. Провести ревью

# Финальный вывод
Заверши работу **только** JSON-сообщением в последнем сообщении. После вывода JSON работа прекращается.
Feedback заполняй только в том случае, если есть оишбки, учти, что нужно вывести ВАЛИДНЫЙ JSON, который будет парситься. Не используй символы-литералы и прочее, что потенцинциально может сломать JSON
