## Правила работы с поиском элементов

Для получения всех AI-атрибутов на странице используй **только** этот код:

```typescript
const aiOutput = await page.evaluate(() => {
  const lines = [];
  const indent = '\t';

  function walk(node, depth) {
    const dataAi = node.getAttribute?.('data-ai');
    const descAi = node.getAttribute?.('description-ai');

    if (dataAi || descAi) {
      let part = '';
      if (dataAi) part += `data-ai=${dataAi}`;
      if (descAi) part += (part ? ' ' : '') + `description-ai=${descAi}`;
      lines.push(indent.repeat(depth) + part);
    }

    for (const child of node.children) {
      walk(child, depth + 1);
    }
  }

  walk(document.body, 0);
  return lines.join('\n');
});
```

- Если в результате выполнения этого скрипта **не находится** нужный элемент — ты **обязан выбросить ошибку** и завершить работу.
- **Никогда** не анализируй страницу иным способом, за исключением момента, когда тебе нужно понять с каким компонента с data-ai атрибутом ты работаешь, чтобы найти/создать его в atf (делай это сразу, даже можешь видоизменить скрипт, что это было автоматически).
